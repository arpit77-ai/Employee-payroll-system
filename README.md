# Employee-payroll-system
Console-based Employee Payroll System in Java demonstrating OOP concepts: abstract classes, inheritance, and polymorphism across Full-Time, Part-Time, and Manager employee types. Features salary/overtime calculation, custom exceptions, file persistence via serialization, payslip generation, sorting, and search — all in a single menu-driven class.

Project Overview: Introduction to the console-based Employee Payroll System.

Features: Breakdown of employee types (Full-Time, Part-Time with overtime, Manager with bonus/tax), payslip export, data persistence, and analytics.
Architecture & Class Mapping: Explanation of classes (Employee, FullTimeEmployee, PartTimeEmployee, Manager, PayrollSystem, Payslip, FileStorage, custom exceptions).

Mathematical Compensation Formulas: Overtime and gross/net calculation equations.

Prerequisites & Compilation: Step-by-step instructions to compile and run via standard commands and direct JDK path on your machine.

Interactive CLI Guide: Guide to menu options and workflow examples.
